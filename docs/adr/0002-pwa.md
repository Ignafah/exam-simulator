# 0002 — PWA plutôt qu'application mobile native en v1

Statut : Proposée

## Contexte

Les utilisateurs révisent principalement sur téléphone, mais aussi sur ordinateur.
L'équipe est réduite et maintient déjà une API .NET et un front React.

## Décision

Le front est une seule application React installable en PWA (`vite-plugin-pwa`),
plutôt qu'une application native (iOS/Android) en v1.
Le service worker ne fait que précacher les fichiers de l'application (pas de cache des appels API) ;
le mode hors ligne complet est hors périmètre v1.

## Conséquences

- Une seule base de code pour le web et le mobile, pas de passage par les stores.
- L'installation sur l'écran d'accueil et les mises à jour automatiques sont assurées par le manifeste et le service worker.
- Les capacités natives (notifications push avancées, etc.) sont limitées ; à réévaluer en v2 si le besoin apparaît.
- Un service worker mal configuré peut servir une ancienne version : `registerType: 'autoUpdate'` limite ce risque.
